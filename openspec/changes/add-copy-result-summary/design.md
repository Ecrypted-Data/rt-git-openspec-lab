# Design

## Context

命令入口 `image_copy.py` 在确认输入目录有效后，按文件名排序遍历第一层，并立即复制受支持的图片。当前没有累计结果，复制循环结束后直接退出。

## Goals / Non-Goals

**Goals:**

- 在现有复制循环中累计成功复制数与第一层跳过数。
- 在循环结束后追加固定格式的汇总行。
- 保持逐文件日志、参数解析和错误处理不变。

**Non-Goals:**

- 不处理输出目录不存在的问题；该行为属于 Issue #2。
- 不递归统计子目录内容。
- 不新增命令行参数或依赖。

## Decisions

- 在循环前初始化两个计数器，复制成功后再增加 `Copied`，避免把复制失败的文件计入成功数。
- 只对 `path.is_file()` 为真的条目分类：支持扩展名的复制，其余计入 `Skipped`；目录不进入任一计数。
- 扩展名继续使用现有的 `path.suffix.lower() in SUPPORTED_EXTENSIONS` 规则。
- 汇总行在循环结束后统一打印，确保它始终位于逐文件日志的最后。

## Risks / Trade-offs

- 复制过程中抛出异常时程序仍按原有方式失败，不会打印汇总；这与“成功执行后输出汇总”的规格一致。
- 输出目录不存在时仍会在第一张图片复制时失败，需由 Issue #2 单独修复。
