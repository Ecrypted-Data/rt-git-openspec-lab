# Design

## Context

当前入口是单文件脚本 `image_copy.py`：校验输入目录后，用 `sorted(source.iterdir())` 遍历第一层，对 `is_file()` 且扩展名小写后属于 `{".jpg", ".jpeg", ".png"}` 的项执行 `shutil.copy2` 并逐行打印。没有测试，也没有既有的计数状态。规格见 `specs/image-copy/spec.md`。

## Goals / Non-Goals

**Goals:**

- 在同一次遍历中累计复制与跳过数量，不额外扫描目录。
- 汇总行只在整批复制成功后输出，失败路径与现有行为完全一致。

**Non-Goals:**

- 不改变参数解析、退出码、逐文件日志格式和扩展名集合。
- 不递归子目录，不统计目录或其他非普通文件。
- 不引入日志框架或配置项。

## Decisions

1. **在现有循环中计数，而不是复制结束后重新遍历目录。** 重新遍历会重复 I/O，且在复制过程中目录变化时统计与日志可能不一致。循环内累加天然反映实际复制结果。
2. **按分支区分计入项。** 现有循环只处理图片；把条件拆成 `is_file()` 下的“受支持则复制并 `copied += 1`，否则 `skipped += 1`”，可确保子目录不进入任一计数，且 `Skipped` 只含第一层普通文件。
3. **汇总在循环之后用单条 `print` 输出。** `shutil.copy2` 失败会抛异常并终止，因此汇总自然不会出现在失败输出中，无需额外的 try/except 或成功标志。
4. **扩展名继续使用 `path.suffix.lower()` 与同一集合比较。** 复用现有规则即自动满足大小写不敏感，Copied 与复制判定不会分叉。

## Risks / Trade-offs

- [符号链接指向文件会被计为普通文件] → 沿用现有 `is_file()` 判定的既有语义，不在本次变更内改变。
- [汇总行与原有日志共用 stdout] → 规格要求追加在逐文件日志之后，保持工具可管道处理的简单模型；不改用 stderr。
