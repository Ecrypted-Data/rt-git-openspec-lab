# Proposal

## Why

批量复制结束后终端只有逐行 `Copied ...` 日志，处理大量图片时需要回滚屏幕才能确认复制总数，也无法判断输入目录里有多少普通文件被跳过。在现有日志末尾补一行汇总即可让结果一眼可见。

## What Changes

- 成功完成一次批量复制后，在逐文件日志之后追加一行 `Copied: <数量> | Skipped: <数量>`。
- `Copied` 统计本次成功复制的 JPG、JPEG、PNG 文件，扩展名匹配沿用现有规则（忽略大小写）。
- `Skipped` 只统计输入目录第一层中扩展名不受支持的普通文件；子目录及其内容不计入任一项。
- 输入目录没有可复制图片时仍正常退出并打印汇总。
- 命令行参数、复制行为、失败时的报错与退出码保持不变；复制失败时不打印成功汇总。

## Capabilities

### New Capabilities

- `image-copy`: 批量复制受支持的图片文件，并在成功结束时输出复制与跳过的统计汇总。

### Modified Capabilities

无。

## Impact

- 代码：`image_copy.py` 的复制循环与输出。
- 接口：新增一行标准输出，现有参数和逐文件日志格式不变。
- 测试：新增基于 `unittest` 的集成测试，覆盖样例目录、无图片目录、空目录。
- 依赖：仅使用 Python 标准库，无新增依赖。
