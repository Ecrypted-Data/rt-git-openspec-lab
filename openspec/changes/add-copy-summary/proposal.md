# Proposal

## Why

批量复制执行完成后，终端只逐行输出 `Copied <文件名>`。处理大量图片时，需要滚动日志逐条计数才能确认一共复制了多少张，也无法看出输入目录第一层有多少扩展名不受支持的普通文件被跳过。补一行结果汇总，可以让一次运行的结果在同一条命令输出末尾直接核对。

## What Changes

- 在现有逐文件日志之后追加一行汇总，格式为 `Copied: <数量> | Skipped: <数量>`。
- `Copied` 统计本次成功复制的 JPG、JPEG、PNG 文件，扩展名匹配沿用现有规则，区分格式时忽略大小写。
- `Skipped` 只统计输入目录第一层中扩展名不受支持的普通文件；子目录及其内容不计入任一项。
- 输入目录中没有可复制的图片时，仍正常退出并打印汇总。
- 命令行参数、现有逐文件日志、复制行为，以及输入目录不存在时的报错保持原样。

## Capabilities

### New Capabilities
- `image-copy`: 图片批量复制工具的命令行行为，包括支持的扩展名、目标目录写入方式、逐文件日志，以及本次新增的运行结果汇总统计。

### Modified Capabilities

（无）

## Impact

- 代码：`image_copy.py`。改动集中在 `main()` 的遍历逻辑，新增两个计数器和一行汇总输出。
- 命令行：参数、退出码语义不变；标准输出在末尾新增一行汇总。
- 依赖与兼容：继续只使用 Python 标准库，不新增依赖；逐文件日志行数和顺序不变，现有调用方式无需调整。
