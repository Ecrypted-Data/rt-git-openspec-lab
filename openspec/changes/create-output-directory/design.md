# Design

## Context

命令入口在确认输入目录有效后，直接将文件复制到指定输出路径。目标目录或其父目录不存在时，第一张图片的复制会失败。

## Goals / Non-Goals

**Goals:**

- 让不存在的输出目录可直接作为参数。
- 保留支持的图片格式和现有命令行参数。
- 输入目录无效时不创建任何输出目录。

**Non-Goals:**

- 不递归复制子目录内容。
- 不改变文件名、扩展名匹配规则或逐文件日志。

## Decisions

- 先执行现有的输入目录校验；校验失败时 `parser.error` 直接退出，不会进入目录创建逻辑。
- 校验通过后调用 `args.destination.mkdir(parents=True, exist_ok=True)`，一次创建缺失的父目录和目标目录。
- 使用 `exist_ok=True` 保留已存在输出目录的现有复制行为；不额外检查目录是否为空。
- 只使用标准库，不新增依赖。

## Risks / Trade-offs

- 如果复制过程中失败，已创建的空输出目录会保留；这不影响 Issue #2 规定的成功路径。
- 如果目标路径是已存在的普通文件，创建目录仍会失败；该场景不在本 Issue 的验收范围内。
