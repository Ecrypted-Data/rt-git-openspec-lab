# Spec Delta

## Purpose

定义批量复制工具在输出目录缺失时的准备行为，让有效输入无需手动建目录，同时保持已有目录和错误路径不变。

## ADDED Requirements

### Requirement: 自动准备输出目录

工具 SHALL 在确认输入目录有效后，创建指定输出目录及缺失的父目录。输出目录已存在时 MUST 继续使用，不得清空或报错。

#### Scenario: 多级输出目录不存在

- **WHEN** 输入目录有效，且指定的输出目录及其父目录均不存在
- **THEN** 工具创建完整目录链并成功退出

#### Scenario: 输出目录已存在

- **WHEN** 输入目录有效，且指定的输出目录已存在
- **THEN** 工具保持目录内容不变，并正常复制受支持图片

### Requirement: 无效输入不创建输出目录

输入目录无效时，工具 MUST 保持原有输入错误提示和非零退出，且 MUST NOT 创建输出目录。

#### Scenario: 输入目录不存在

- **WHEN** 指定的输入目录不存在
- **THEN** 工具提示输入错误，以非零状态退出，输出目录不被创建

### Requirement: 保持复制结果

输出目录就绪后，工具 SHALL 复制受支持的 JPG、JPEG、PNG 文件并保留原文件名，MUST NOT 复制 `notes.txt` 等不支持文件。

#### Scenario: 样例目录复制

- **WHEN** 使用 `examples/input` 和不存在的多级输出目录运行
- **THEN** 输出目录包含三张受支持图片，且不包含 `notes.txt`

#### Scenario: 没有受支持图片

- **WHEN** 输入目录有效但第一层没有受支持图片
- **THEN** 工具正常退出，输出目录仍被创建
